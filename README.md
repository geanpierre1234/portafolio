# Portafolio de Charles Ledesma Torres

Portafolio personal desarrollado con HTML, CSS y JavaScript. Incluye presentación, proyectos realizados, perfil y contacto.

## Ver el sitio localmente

Abre `index.html` en tu navegador. No requiere instalación ni compilación.

## Archivos

- `index.html`: contenido y estructura.
- `styles.css`: estilos y diseño adaptable.
- `script.js`: perfiles, contacto e interacciones.
- `IMAGEN/`: avatar y capturas de los proyectos.

## Publicar con GitHub Pages

En el repositorio, abre **Settings → Pages**. Selecciona **Deploy from a branch**, la rama `main` y la carpeta `/ (root)`. Guarda la configuración.

## Actualizar el CV

Guarda el PDF en `assets/` y configura su ruta en `profile.cv` dentro de `script.js`.
